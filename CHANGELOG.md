# Changelog

## [2.2.2] — 2026-09-07

### Исправлено
- Aeternia ID длиннее 8 символов (например, 32-символьный из `/dns-query/…`) больше не отклоняется: интерфейс и macOS-помощник принимают hex-код длиной от 8 до 64 символов.

## [2.2.1] — 2026-09-06

### Исправлено
- Установка из старой версии с двойным sudo больше не требует ненулевого SUDO_UID: используется обычный пользователь из sudo, текущего сеанса Mac или явный `--user`.
- Один и тот же определённый пользователь используется при выдаче прав, переносе серверов и финальной проверке помощника.

### Добавлено
- `install-macos.sh`: установка одной командой независимо от старого лаунчера, проверка версии скачанного пакета, установка зависимостей от пользователя и открытие восстановленного приложения.
- Регрессионные тесты вложенного sudo, отсутствующих переменных окружения и выбора пользователя.
- GitHub Actions с проверкой установки/повторной установки/удаления на macOS.

## [2.2.0] — 2026-09-06 (macOS ещё не проверена)

### Исправлено
- «Без прокси» на macOS восстанавливает сохранённые ручные DNS/DHCP всех затронутых подключений до остановки службы.
- Проверяются коды завершения и фактические DNS; ошибки не маскируются сообщением об успехе.
- Восстановление и очистка DNS-кэша выполняются без перезагрузки, журнал сохраняется для повторной попытки.
- Проверка ответа нового DNS выполняется до перенаправления системного DNS; при ошибках предусмотрен откат.

### Изменено
- Интерфейс macOS запускается от пользователя. После однократной установки запуск и переключения не требуют пароля.
- Привилегированные операции вынесены в отдельный root-owned помощник с фиксированными операциями и узким правилом sudoers.
- У Aeternia отдельные служба, защищённая копия DNS-движка и конфиг; файлы Homebrew больше не изменяются.
- Добавлены миграция старого локального DNS, удаление с предварительным восстановлением и инструкция MACOS.md.
- Единый установщик включает новые файлы; сборщик поддерживает BSD/GNU base64.
- Обновление системного помощника на macOS выполняется установщиком с подтверждением администратора.

### Проверки
- Автоматические тесты транзакций DNS, ошибок, миграции, интерфейса без root и содержимого установщика.
- Реальный запуск установщика и сетевых операций на macOS требуется перед публикацией.

## [2.1.3] — 2026-07-26

### Добавлено
- 🚫 Добавлен режим **«Без прокси»** (клавиша `0`), возвращающий конфигурацию `dnscrypt-proxy.toml` к значениям по умолчанию, останавливающий службу и сбрасывающий системный DNS.

### Исправлено
- 🍎 Исправлена критическая ошибка перезапуска службы на macOS (`cannot as root!`), возникавшая из-за ограничений Homebrew при запуске под `sudo`. Теперь управление службой осуществляется напрямую через `launchctl` и `/Library/LaunchDaemons/`.
